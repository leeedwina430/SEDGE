\textbf{Sample counts.} Each seed draws a 200,000-root candidate pool, then selects 20,000 retained training rows and 2,000 retained validation rows. There are three seeds. Binary testing uses 2,000 conditional reference samples at $(1,1)$. Continuous testing uses 64 held-out target pairs, with 32 reference draws per target (2,048 outputs). Continuous targets are drawn from the population conditional on the held-out rectangle; they are not assumed uniform in that rectangle.

\section*{Bridge compatibility and selection audit}
For a fixed target $z$, define $F_i(z_i)=\{c:\exists x_{\mathrm{private}}\text{ in root support with }f_i(x_{\mathrm{private}},c)=z_i\}$. Thus compatibility means that a private root \emph{can} satisfy the specification; it is not sufficient for an arbitrary generated private root to satisfy it.

\textbf{Away from the center.} For the three scalar continuous mechanisms, let $g(c)=c$, $c^3$, or $3c^2-2c^3$. Throughout the specified test rectangle,
\[
F_1(z_1)=[0,z_1/0.6],\qquad
F_2(z_2)=[g^{-1}((z_2-0.8)/0.6),1],\qquad
F_1\cap F_2=[g^{-1}((z_2-0.8)/0.6),z_1/0.6].
\]
The joint width ranges are $[0.045,0.055]$ (Linear), approximately $[0.043835,0.056223]$ (Cubic), and $[0.045829,0.054171]$ (Smoothstep). For 2D, replace $0.35$ by $z_1$ and $0.65$ by $1-z_2$ in the inequalities; the audited joint area varies approximately from $0.00840$ to $0.00947$.

These continuous conditional rates are \textbf{band averages}, not verified bounds on $\sup_{z_i\in I_i}P(S=0\mid Z_i=z_i)$. Root independence holds before selection; selection can distort the observed factors. Small exclusion and retained marginal support do not prove an undistorted likelihood or accurate learned models. Geometric compatibility above uses exact target equations; the result evaluator separately allows $|f_i(X)-z_i|\leq0.005$ on each continuous specification and also requires root support.
